# Frozen integration contracts

ES modules, no new runtime dependencies. Shared helpers in ../ui.js: escapeHtml(value), icon(name,size=20), formatMetric(value,metricKey), formatDate(iso,{short=false}={}), metricLabel(metricKey), evidenceButton(ids,label='View evidence'). formatMetric returns complete formatted text (including units).

Page renderer exports return an HTML string and receive ctx = {state,filters,summary,comparison,insights,sources,events}. state={screen,from,to,selectedDate,sourceIds,metricKey}; filters={from,to,sourceIds,metricKey?}. Data service exports from dist/data/demo-service.js: selectEvents(filters), summarize(filters), comparePeriods(filters), buildInsights(filters), answerQuestion(question,filters), resolveEvidence(ids), all async. dist/data/demo-data.js exports sources, events, checkins, metrics, demoProfile, DEMO_START='2026-10-01', DEMO_END='2026-10-30', TIME_ZONE='America/Los_Angeles'. metrics is a keyed object each {key,label,unit,color}; demoProfile {name,initials,description}. sources/events/checkins arrays.

summary={coverage:{records,sources,daysWithRecords,daysWithCheckins,latestObservedAt,metrics:{[key]:{observedDays,missingDays}}},seriesByMetric:{[key]:Array<{date,value:number|null,recordIds:string[]}>},calculations:CalculationResult[]}. Each summary calculation has metricKeys:[key], calculationType:'summary',values:{mean,median,min,max,total,observedDays,missingDays}; total applies steps, null otherwise. comparison={status:'supported'|'insufficient_data',previousRange:{from,to}|null,currentRange:{from,to}|null,excludedDates:string[],calculations:CalculationResult[],limitations:string[]}. Period calculations values:{previousMean,currentMean,delta,percentageChange,previousCount,currentCount,previousMissingDays,currentMissingDays}.

CalculationResult and Insight and IntelligenceResponse fields follow PRD camelCase. insight.calculationId links complete calculation inputs; evidenceRecordIds actual evt IDs. resolveEvidence accepts evt or calc IDs and returns {records,calculations}; unknown IDs reject.

ROOT delegated click attributes: data-screen='overview|connect|recovery|insights|timeline|intelligence|reports|about'; data-day=ISODate; data-metric=metricKey or 'all'; data-range='7|14|30'; data-view-source=sourceId switches to filtered Timeline; data-ask=question switches to Intelligence and submits; data-question=question submits in Intelligence; data-evidence=JSON array of evt/calc IDs (use evidenceButton); data-print; data-reset; data-clear-filters. Root handles all. Source filter checkboxes name='source' value=sourceId root handles change. Don't bind duplicate events. All evidence inline, no drawers.

Data source selection omitted means all, [] means none. Dates inclusive and Pacific. Default selectedDate Oct30. formatDate must not use host timezone. Metric keys sleep_duration,steps,resting_heart_rate,energy. A filter metric other than all may yield empty other series: show intentional missing states.
